Lower draws fewer pixels: faster on the car's processor and lighter on memory, a little blurrier. The page keeps its layout.

More memory lets bigger pages and games load, but leaves less to the car's own screens, which may get slower while a big page runs. Only the browser itself can run out.

Make room pauses the Moonlight and Cast tools while the browser is on (Cast's cluster map too) and starts them again when it goes off.

GPU mode (experimental): WebGL on the car's own graphics driver instead of the CPU. Chromium restarts for it, and it is off again whenever the tool starts. If the screen ever freezes or goes black, the car restarts and comes back without it.
