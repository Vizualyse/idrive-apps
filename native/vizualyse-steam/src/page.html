Steam on the car

Playing

Nothing.

The game's pictures go straight to the car's own screen compositor (Winston), in full colour. Compatibility mode sends them through mgu-render instead, as older versions did; Steam does that by itself if Winston can't be reached. From the next Show.

Only while parked. A hidden game keeps running; Stop ends it. Games can't be controlled yet (no touch or gamepad input in this version).

Performance graphs

The running game's (or the last one's) measurements, a point every 10 seconds, the last hour. Read only while this is open.

Library

No games yet: install one below.

Install a game

The app id is the number in the game's Steam store address (store.steampowered.com/app/2868840/...). The account must own it. The Windows version is downloaded.

Steam account

Steam asks for the password and a Steam Guard code once, during the first install, right on this page. The car keeps only Steam's sign-in token, never the password.

Settings

Picture, frames and memory apply from the next game. More memory lets bigger games run but leaves less to the car's own screens. Upscaling applies at once: FSR sharpens a small picture (896x320, say) as it is enlarged to the screen, for some of the graphics chip's time.
