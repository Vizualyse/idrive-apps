# 07 · The cluster's own direction list over the mirror

## Why

With navigation running, the cluster draws its own turn-by-turn list (from
CarPlay's route guidance) **on top of** the centre area, over our mirror.
Nothing can be drawn above it.

## Options

1. Turn the cluster's list off in iDrive, if this firmware has a setting
   (Instrument cluster or Navigation menus: route guidance, next turn). Check
   the menus; note the path here if it exists.
2. Place the mirror where the list is not: the map target is 1088x480;
   if the list covers one side or a strip, offset the layer into the free
   part (a placement option per layout).
3. Prefer the HUD layout while navigating (it has no competing list).

## Work

- A photo or description of where the list sits and how big it is.
- If option 2 fits: an `x`/`y`/size placement per layout and output, and a
  way to pick it on the phone page.

## Done when

- With navigation running, the mirror on the cluster is fully visible.
